Run from the repository root after `pnpm build`. Install the isolated QA dependencies with `npm install --prefix scripts/qa`, then `cd scripts/qa` and `npx playwright install chromium`. Return to the repository root and run `node scripts/qa/browser.cjs` and `node scripts/qa/lighthouse.mjs`. Python 3 provides the browser audit static server. Optionally set CHROMIUM_PATH to an installed compatible Chromium executable. The recorded audit used Chromium 153 and Lighthouse 13.4.1. Scores vary with runtime and hosting; repeat on the actual Vercel preview. Full raw Lighthouse JSON/HTML is regenerated locally; committed metrics capture measured category scores and payload totals.

The optional form integration fixture uses synthetic data and intercepts an `.invalid` URL. Build with `NEXT_PUBLIC_LEAD_ENDPOINT=https://xoxo-test.invalid/lead pnpm build`, run `node scripts/qa/form-fixture.cjs`, then rebuild without that variable. It verifies invalid names/contacts, a 500 error, a 201 success, data-room intent and attribution. It is not proof of live delivery.

Run `node scripts/qa/motion.cjs` against the default build to check video playback/pause, responsive source switching, dynamic reduced motion and total compressed JS after interacting with the calculator.
