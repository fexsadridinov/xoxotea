# XoXo Simplified Chinese font subset

Noto Sans SC, Google Fonts, SIL Open Font License 1.1 (NOTO-OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
Downloaded 2026-09-14; source SHA-256: a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da

Instantiated at weight 400 and subset to the Chinese website, recipe catalogue, shared punctuation and printable ASCII. Renamed XoXo SC. WOFF2 is self-hosted by next/font/local; TTF embeds into the Chinese PDF. No font request to Google occurs at runtime. Extend the subset when Chinese copy gains new characters.

The pre-existing OFL.txt belongs to thesis-500.woff2 and is preserved.
