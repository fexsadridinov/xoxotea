# XoXo Tea / v2

Technical tea-and-numbers website in Ukrainian, English and Russian published from `main`. The 14 September localization revision adds Russian home, menu and investor pages. All four calculator inputs now accept zero, with existing maxima, defaults, scenario results and cost assumptions preserved. Gross margin is explicitly undefined at a zero ticket; remaining fixed costs are still charged.

## Run

Node 24, pnpm 11.19.0. `pnpm install --frozen-lockfile`, `pnpm dev`, `pnpm build`, `pnpm lint`, `pnpm test:model`.

Next.js static export with nine localized routes. The Vercel Next.js preset must use `.next` for build metadata; the repository and Vercel dashboard both use `.next`. Portable HTML exports to `out`.

## Published release and remaining quality gates

The owner authorized publication on 14 September 2026. PR #5 is merged and the Russian site is live at https://xoxotea.vercel.app/ru/. See `DEPLOYMENT.md` for local setup and direct Vercel commands. Publication does not mean every quality gate has passed.

Higgsfield returned insufficient credits for the 36-frame turntable. Three still variants have observed consistency defects and require corrections. The new design must not be described as passing the requested asset gates. See `ACCEPTANCE.md` and `ASSETS.md`.

The product stage uses an honest static fallback. `CupSequence.tsx` supports 36 progressively decoded frames when the missing sequence is supplied in `public/sequence/manifest.json`. No fabricated rotation or duplicate frame sequence is included.

## Delivery configuration

Optional build-time environment values: `NEXT_PUBLIC_SITE_URL`, `NEXT_PUBLIC_LEAD_ENDPOINT`, `NEXT_PUBLIC_CALENDAR_URL`. No private secrets belong in public values. The form downloads an explicitly unsent request when no endpoint is configured. A connected endpoint must durably accept the request and return 2xx; errors retain form entries. Calendar is explicitly pending until supplied.

## Content and media

All UI prose is in `content/uk.json`, `content/en.json` and `content/ru.json`. IBM Plex Sans and Mono are self-hosted by Next.js. The six cup images are new generation outputs; no previous people, venue, city, packaging or lifestyle imagery remains in the current tree. Source generations are retained outside the product tree until approved. Compressed working previews remain clearly identified in the asset ledger.

PDFs are generated by `scripts/onepager-v2.py`. `scripts/media-v2.py` accepts the local generation download directory and produces AVIF/WebP derivatives.

Language root layouts emit the correct HTML `lang` before hydration. The language menu preserves the current view and supports keyboard dismissal. The obsolete `/ru` redirect is removed. See `LOCALIZATION.md` for terminology and the refinement log.
